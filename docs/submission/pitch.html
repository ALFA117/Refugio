The problem

Most social worlds are empty rooms.

They only feel alive during a hosted, scheduled event. Walk in at a random hour and you get a beautiful, lifeless space. That empty-venue failure is exactly what this hackathon disqualifies — an experience that needs a host doesn't count. Refugio is built so the social moment emerges from whoever walks in, at any hour, with zero coordination.

How it works

Seven systems, one fire.

Why it wins

Judged on the thing it's built around.

Social Value · core

The mechanic is the signal

The fire is a live count of who's present, and the mini-game hands strangers a shared goal within seconds of arriving. Cooperation is the default state, not an opt-in.

Hard requirement

No host, ever

Rounds are arbitrated by Decentraland's authoritative server on its own clock — not a designated "host" client. There's no point of coordination that can be absent. Verified by entering cold.

Retention · discovery

A reason to return

Persistent embers and an in-world leaderboard reward coming back; the referral link turns each guardian into a discovery channel that brings the next one.

Architecture

One codebase, split at the fire.

Client · every player
  • Fire intensity + seats, synced with syncEntity
  • Taps firewood, sends feedFire to the server
  • Reads authoritative state → HUD, flame, leaderboard
  • UI in react-ecs: onboarding, ember count, health bar
Authoritative server · isServer()
  • Runs the round: spawns wood, decays health, ends the round
  • Validates every feed — clients never request rewards
  • Sole writer of Storage: embers + world leaderboard
  • Grants the referral bonus when both play a round together

Decentraland hosts the authoritative server automatically on publish — no external infrastructure, and real anti-cheat by design: the server arbitrates the round it timed itself.
